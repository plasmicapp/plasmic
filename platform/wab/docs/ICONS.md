# Icons

Studio icons are SVG React components generated by Plasmic, not hand-written
files. Most of them come from the `[PlasmicKit] Icons` project
(`oT38tGyqov9SPWHpf3Y2Rf`) and land in
`src/wab/client/plasmic/plasmic_kit_icons/icons/PlasmicIcon__*.tsx`. A few
older ones live under the other `src/wab/client/plasmic/plasmic_kit_*/`
directories.

## Adding a new icon

1. Check whether an existing icon works first. There are ~600 of them, so
   search `src/wab/client/plasmic/plasmic_kit_icons/icons/` before drawing
   anything new.
2. Add the SVG as an icon asset in the `[PlasmicKit] Icons` Plasmic project,
   following the conventions below.
3. Sync it into the repo:

   ```
   pnpm plasmic:sync
   ```

   This writes the generated component and registers it in `plasmic.json`.
   Commit both.

4. Give it a semantic name in `src/wab/client/icons.tsx` rather than importing
   the generated `PlasmicIcon__*` module all over the codebase.

## SVG conventions

New icons should match the existing set:

- `viewBox="0 0 24 24"` (the set is drawn at 24×24, even though it renders at
  16px by default)
- `fill="none"` on the `<svg>` element; draw with strokes, not fills
- `stroke="currentColor"` so the icon inherits text color — never hardcode a
  color
- `stroke-width="1.5"`
- `stroke-linecap="round"` and `stroke-linejoin="round"`
- Prefer a single `<path>` over many primitives
- Keep the artwork inside the 24×24 box with a consistent margin instead of
  bleeding to the edges, so icons look the same weight when placed side by side

An existing icon that follows all of the above, useful as a reference:
`src/wab/client/plasmic/plasmic_kit_icons/icons/PlasmicIcon__Braces.tsx`.

## Using an icon

Render icons through the `Icon` widget, which applies the standard sizing
(16px) and the `custom-svg-icon` class:

```tsx
import { Icon } from "@/wab/client/components/widgets/Icon";
import BracesIcon from "@/wab/client/plasmic/plasmic_kit_icons/icons/PlasmicIcon__Braces";

<Icon icon={BracesIcon} />;
```

Pass `size` to override the default, and `monochromeExempt` for the rare icon
that should keep its own colors.
